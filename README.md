# Space-Ball-Pool
Space Ball Pool is a local two‑player 3‑D pool game set in an ambient space environment that reimagines classic billiards. From the main menu, players can start a match, view a tutorial, adjust settings, or exit. During gameplay, arena gridlines and shaders aid visibility, sound effects accompany ball collisions and scoring, and pop‑up messages provide continuous feedback. A shot power gauge on the right display is controlled by mouse movement, adding a skill‑based mechanic to the competitive experience.

The project falls within physics‑based simulation and user‑centered interface design, built entirely in Unity. It draws heavily on human‑computer interaction and UX principles, ensuring clear menus, readable HUD elements, timely feedback, and well‑explained rules. Features such as the power gauge, score display, pop‑ups, and rule descriptions all prioritize player experience. As a local two‑player competitive game, it also sits squarely in the domain of multiplayer game design.
